# Customer Information Architecture (from handoff)

## Screens (Stage 2–3)

1. OTP Request
2. OTP Verify
3. Registration form (after verify if new)
4. Home / Assets (money_toman, gold_weight_g)
5. Custody list (امانات من)
6. Quote request (blocked until price provider)
7. Order history (after Stage 4+)

## Rules

- Persian RTL, mobile-first PWA
- No client-side financial calculation
- Loading / empty / error states on every screen
- High-fidelity prototype gate before broad UI expansion
